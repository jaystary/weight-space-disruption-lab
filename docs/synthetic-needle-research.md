# Two synthetic tests of direct weight programming

Investigate both context retrieval and factual memory with an actual researcher inspecting numerical tensors and writing internal-weight patches. Preserve the quantitative goal: at least ten percentage points above an unchanged baseline on fresh held-out questions, valid paired significance at p <= .05 and no accuracy loss in registered guard tasks. Prompts and decoding match between arms. No gradients or replacement classifier.

Arithmetic experiments reuse a published patch and remain replication controls. A replication pass alone cannot satisfy the additional request for Astra to discover its own edits. One authenticated request pinned to gpt-6-astra returned code and known usage; CLI events did not independently report backend identity. Its program failed on missing API bindings. A separately registered controller correction reached tensor loading, then failed on another missing import. Both failures and partial output remain; neither is an efficacy result. Future kernel bindings are explicit.

| Track | Construction | Evidence sought |
|---|---|---|
| Context retrieval | Fictitious entity/color facts among distractors, with four target positions. Development pilots choose among 64, 256 and 512 records; then 16 development and 48 fresh final cases. | A fixed internal patch improves retrieval of unseen facts and haystacks under unchanged prompts and decoding. |
| Weight memory | Sixteen independently sampled fictitious entity/color associations are supplied as write requests. One development question and one withheld paraphrase per fact. Supporting fact text is absent from final questions. | The patched checkpoint recalls inserted facts on unseen wording while preserving unrelated tasks and unwritten-entity behavior. |

Memory facts, not paraphrases, are statistical units. This measures recall of inserted facts; it does not establish knowledge of facts never supplied. No answer-bearing system message, retrieval cache, lookup table, output-head replacement or activation injection may supply a final answer.

The researcher gets immutable BF16 tensor snapshots and a restricted NumPy execution interface. Twenty-five internal matrices are editable: selected MLP down projections and attention Q/K/V/output projections. No embeddings, output heads or norms. Each candidate is relative to immutable base, limited to 262,144 changed BF16 entries and 16 MiB. The harness validates exact replacements, records tensor and input hashes and requires exact restoration. Restoration failure stops editing.

Development features include linear-module inputs and outputs at both the final prompt position and the fact/entity span, final residual/normalized hidden states, supported versus unsupported memory contexts, and read-only answer-token output directions. Last-query attention is reconstructed from native normalized and rotary Q/K with FP32 scores: fact-span mass, recency mass, entropy and mean output gate by head. These are approximate diagnostic probabilities, not exact SDPA-kernel attention maps or causal attributions. Actual weight interventions and development forwards must test causal hypotheses. No invented neuron meanings or full-network map claims.

Each track has four bounded Astra calls, including diagnostic-only programs and failures. A valid candidate triggers the fixed development generation panel; arbitrary caller-defined GPU forwards are unavailable. Rank candidates by development exact accuracy, then target-first-token margin, then fewer changed entries. Both selected patches freeze before either final or guard cohort opens. If no patch beats baseline rank, leave that track's final cohort sealed and record no candidate.

Goal-level multiplicity covers four planned claims, including both arithmetic replications: adjusted p=min(1,4*raw p). Earlier stage and two-trial-family decisions remain preserved. Final success requires at least ten percentage points gain, adjusted p<=.05, complete one-shot scoring and no accuracy decline in any registered guard family. Guards cover exact copying and arithmetic; memory additionally checks unwritten entities. No final retry, final-guided selection or uncorrected search for a favorable result.

A gradient-free memory hypothesis is to derive a local rewrite from differences between supported and unsupported representations. It remains untested. Standard ROME optimizes its auxiliary target with Adam/backpropagation and therefore cannot be adopted unchanged under this contract. One-off algebraic internal rewrites are allowed; multi-example regression, iterative loss fitting and random weight search are not.

Preparation checks cover synthetic split construction, strict scoring, call limits, immutable restoration, failure accounting and prompt selection. A native tiny-transformer test verified that tracing captures fact-span/head features without changing model output. Tokenizer integration on authored 512-record fixtures produced 9,939–9,986 input tokens, below the 16,384 limit. These checks are not target-checkpoint efficacy evidence. Execution has now started after the preceding evaluation passed closure; final outcomes remain pending. An unscored trace smoke and restoration check precede scored development; closure auditing still gates outcome claims.

Keep actual requests, returned programs, conversations, raw cases and operating details private. Public material contains generic templates, authored source, synthetic checks and aggregate evidence. All experiment computation remains remote; no additional resources or budget extension.
