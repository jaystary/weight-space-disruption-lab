# Independent weight-edit results

GitHub survey, 3 November 2026, around 04:30 UTC. A search for the exact phrase “weight-space programming” across names, descriptions and READMEs returned 44 public repositories. The upstream logs had 34 forks. These counts overlap, include news feeds and scaffolds, and cannot estimate the number of people experimenting. The examples below come from commit-pinned reports and the released model card. Their numbers are the respective teams’ measurements.

| Experiment | Measured outcome | What the experiment establishes |
|---|---|---|
| GPT-6-designed output-weight edit on pretrained Qwen2.5-0.5B | 15/32 to 23/32. Eight repairs, zero regressions. Two norm-matched controls both scored 15/32. | All eight repairs removed unwanted Markdown fences from JSON answers. A deterministic program calculated 896 values from practice activations after GPT-6 chose the strategy. The separate same-family regression split improved from 7/12 to 10/12. The earlier internal MLP-column edit had no effect. [Results](https://github.com/KevinmKrieg/weight-smithing/blob/9c2641a22548fcbdcc4de4c89b15737c44991e7d/results/qwen-output-row-pilot-002.json) · [Design and limits](https://github.com/KevinmKrieg/weight-smithing/blob/9c2641a22548fcbdcc4de4c89b15737c44991e7d/README.md) |
| Agent-discovered hidden bias repair | 35/64 to 64/64. Matched random edit stayed at 35/64. | One hidden-bias change fixed an injected threshold defect. Practice and holdout were separate. The pilot used one 12-parameter synthetic model, with transfer still inconclusive. [Experiment record](https://github.com/jacksonjp0311-gif/WeightBridge/blob/d58c125dea0fb0a3e90afe023e4b7a083a8785ad/results/original_weight_edits/mcp-pilot-18d5cab750/experiment_record.json) |
| Astra-discovered symbol routing repairs | Each of three damaged 632-parameter networks went from 91/112 to 112/112. Healthy control stayed at 112/112. | Six output weights changed per damaged model. All fault types appeared in practice. The held-out inputs covered the rest of a constructed truth table. [Report](https://github.com/Occupying-Mars/toy-weight-repair/blob/84b7b49fb5f616f682de68f34edcdddf9419e3f6/REPORT.md) |
| Independent replay of the authors’ Qwen3.5-0.8B patch | Edited checkpoint reached 51.0% over 500 MATH-500 problems with four samples each. The authors reported 48.1%. | The independent evaluator rebuilt the same patch. Its base smoke test covered only 25 problems, so 51.0% is an edited score, without a full paired baseline in this rerun. [Pinned model card](https://huggingface.co/RikiyaT/Qwen3.5-0.8B-weight-space-programming/blob/d1671a178705bcab7644806d23c535517f35723b/README.md) |
| Answer completion versus correctness, using the published patch | On 24 prompts with thinking enabled, final answers were reached on 6 versus 13 prompts. Fully correct answers remained 5/24 in both arms. | Completion and task correctness can move separately. [Independent paired report](https://github.com/Unjuno/beyond-math-weight-space-programming/blob/58254e148f3d05a109a791c159eb35111fe657fc/docs/local_probe_results.md) |

The closest language-model success repaired a specific output habit. Under this lab’s frozen internal-tensor rules, an output-head edit is outside the eligible set. A prospective extension could target the internal activation that predicts unwanted fences, with one control requesting fenced code and another checking JSON contents. That is a new hypothesis. No external outcome contributes to this lab’s efficacy score.
