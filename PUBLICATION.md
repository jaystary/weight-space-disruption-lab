# Publication boundary

All published images use dark backgrounds and readable light text, including SVG originals, PNG exports, README embeds and future diagrams. Regenerate every companion format when an image changes; inspect the rendered result before publication.

This task-neutral projection contains authored harness code, synthetic tests, experiment specifications, diagrams and aggregate results. Domain names, source labels, task-specific prompt wording and operating locations have been generalized. The code is a reference harness, not the exact executable identity used to produce the historical results. Measured numeric outcomes are unchanged; no new outcome is implied by the generalized prompts.

Private text, individual predictions, agent conversations, actual editor requests, private prompts, credentials, secrets, operating details and model caches are excluded. Generic prompt templates are code. Original manifests, source identities and full evidence remain private. Registered bounds and decision rules are unchanged; original manifest hashes are recorded for custody. Reproduction of the original experiments requires authorized private artifacts. A new dataset or prompt requires a fresh registration.

The public branch has a new clean root to remove earlier task-specific wording from active history. Previously public copies, cached commits or third-party clones cannot be recalled by rewriting a branch.
